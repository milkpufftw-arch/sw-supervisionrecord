# 社工督導記錄小幫手（Social Work Supervision Record Skill）

將社工個別督導的逐字稿、會議摘要或口述重點，整理成專業、客觀且具結構的**社工個別督導記錄表**。

## 功能
- 根據內容辨認**教育性、行政性、支持性**督導功能
- 勾選督導議題與督導策略（僅勾選有證據的項目）
- 將口語化紀錄轉換為中立、不污名化的社工專業書寫
- 區分**主要發現、督導建議、受督者反思**
- 評估督導成效並整理下次追蹤事項
- 預設輸出 Markdown 表格；若使用者要求，透過可用的文件工具（例如 `python-docx`）產出 Word（`.docx`）

## 專案結構

```text
.
├── SKILL.md                     # 技能設定、工作流程與判斷規則
└── references/
    └── record-template.md       # 社工個別督導記錄表範本
```

## 在 ChatGPT 使用
1. 若帳戶／工作區提供 **Skills** 上傳功能，將此技能資料夾打包為 ZIP，內含 `SKILL.md` 與 `references/`。
2. 依 ChatGPT 畫面指示建立或上傳技能。
3. 在對話中選擇該技能或輸入：「請將以下督導逐字稿整理成社工個別督導記錄表，並輸出 Word。」
4. 貼上**已去識別化**的逐字稿或摘要，核對生成內容後再正式使用。

> 上傳選項、可用權限與檔案產生能力會依 ChatGPT 帳戶及工作區而異。

## 範例提示詞

```text
請使用「社工督導記錄小幫手」，依六大項目整理以下督導會議逐字稿。
請區分實際事實、督導建議與受督者回應；無證據的項目不要勾選，
未提供的基本資料請標記「未提供」，並提出下次追蹤事項。

［在此貼上已去識別化的逐字稿］
```

## 隱私與專業責任
- **請勿將真實案主資料、敏感個資或未去識別化逐字稿提交到此公開儲存庫。**
- 生成的督導記錄僅供初稿與行政整理之用，不代表正式評估或處遇決策。
- 最終紀錄與個案評估須由負責社工及督導依機構規範核閱、修正並簽章。
- 處理個資與機密文件時，請遵守機構政策及適用法規。
